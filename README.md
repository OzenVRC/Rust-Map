### Steps to Install Dependencies for the OBS Script

This guide will help you set up everything you need to run the OBS script. Follow these simple steps:

---

#### 1. Install Python
- If you don’t already have Python installed, download and install it from (https://www.python.org).
- Make sure to check the box **"Add Python to PATH"** during installation.

---

#### 2. Install the `keyboard` Library
- Open **PowerShell** or **Command Prompt** (press `Win + R`, type `cmd`, and hit Enter).
- Run this command:

  ```bash
  pip install keyboard
  ```
- If you see a message saying "'pip' is not recognized," you might need to reinstall Python and ensure the PATH option is checked.

---

#### 3. Install OBS Studio
- Download OBS Studio from (https://obsproject.com/) and install it.
- Ensure Python scripting is enabled (it usually is by default).

---

#### 4. Add the Script to OBS
- Open OBS Studio.
- Go to `Tools > Scripts`.
- Click the `+` button to add your script file.
- Follow the on-screen instructions to set it up.

---

That’s it! You’re ready to use the script. Simply hold G & you're good to go!
